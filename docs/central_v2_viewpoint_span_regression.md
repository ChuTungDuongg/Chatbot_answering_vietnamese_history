# Central V2: claim-local viewpoint regression fix

This focused pass starts from the current repository state and preserves the preceding latency/retrieval patch. Verification uses local CPU/fake inference only. The production timings are the user's supplied observations, not a new live-model benchmark.

1. **Exact false-positive root cause.** The previous `_close_reproduction` had a short-span shortcut: if either side had fewer than five normalized words, an exact substring of at least three source words counted as reproduction. “Cách mạng Tháng Tám” has four normalized words. If the source quoted that event label in a reporting context, the annotation was marked attribution-required and every ordinary answer sentence containing the event name could match. `viewpoint_attribution_issues` copied the annotation's `direct_quote` type into the answer issue without proving actual quotation or a sensitive proposition. The production trace is consistent with this exact code path, and a fixture reproduces its prerequisites. The complete production source chunk was not supplied, so the original speaker/context text is not assumed.

2. **Why the CMT8 conclusion became a direct quote.** The event name in the neutral synthesis matched the four-word source annotation. Its surrounding synthesis about Japanese surrender, preparation and popular support did not need to resemble any speech. The source boolean itself was not read by the old validator: this was a permissive annotation-matching bug, rather than a literal `viewpoint_sensitive` boolean branch. Repeating the same neutral conclusion after repair triggered the same rule again.

3. **Old algorithm.** Source annotation detected quotations, reported opinions, first-person speech and a small loaded-language list. For answer matching it used either the short substring shortcut or approximately 0.80 sequence similarity over source-sized windows. Both copied quotations and paraphrases inherited the original annotation type. There was no title-only exclusion or explicit distinction between direct copying and opinion paraphrase. Source excerpts were annotation text, which could unfortunately be only a quoted event title.

4. **New span-based algorithm.** Each candidate must have nonempty annotation text that exists in the actual supplied source body. Provided offsets must exactly recover that text. The source title, alias and sensitivity boolean confer no matching support; a span equal to the normalized title is rejected. Evaluate each answer sentence against the validated annotation, first for direct copying and then for a close sensitive-opinion paraphrase. Source-derived issues report `source_alias`, `type`, `answer_claim`, `matched_sensitive_span`, `overlap_score`, `attribution_hint` and `reason`. Compatibility fields `claim` and `source_excerpt` remain; the latter is the actual matched span. No concrete source span means no source-derived `direct_quote` issue. Separate existing checks for loaded language invented by an answer still run and identify themselves as answer-language checks, without pretending to match a source.

5. **Direct-quote threshold.** A phrase inside answer quotation marks needs at least five contiguous matching normalized words, at least 90% coverage of that answer quotation, and at least three distinct non-function words. Unquoted copying normally needs eight contiguous normalized words, including at least four distinct non-function words. A deliberately narrow exception admits a complete five-to-seven-word first-person quotation, such as “chúng ta nhất định thắng lợi”, even when the answer omits quotation marks. Changed negation prevents a match. Acronym expansion does not inflate the contiguous-copy count: VNCH remains one copied word. Titles never qualify, even when longer than eight words. Supported quotation marks include straight double/single and curly quotation marks.

6. **Opinion-paraphrase policy.** A paraphrase must closely match a specific attributed proposition or loaded source span; merely citing a sensitive source cannot trigger it. The bounded lexical comparison requires at least six words on each side, sequence similarity of at least 0.86, a shared contiguous phrase of at least three words, four shared non-function words and preserved negation. VNCH/full-name normalization is allowed here. Report these matches as `viewpoint_paraphrase`, not `direct_quote`. This is a conservative lexical detector, not semantic entailment; uncertain or loose paraphrases abstain. The Noam Chomsky example is detected, explicit attribution passes, and an unrelated neutral Vietnamization fact from the same source passes without attribution. Speaker labels such as `Noam Chomsky:` are recognized. A related regression also exposed lowercase Vietnamese characters slipping through a broad uppercase range: “văn tuyên bố” could yield the bogus speaker “ăn”, whose substring in “thắng” falsely exempted a quote. Speaker extraction now checks real capitalization and whole words, and attribution matches whole speaker tokens.

7. **Neutral-synthesis policy.** The supplied CMT8 conclusion passes, including the original “lãnh đạo sáng suốt” wording and the requested “lãnh đạo” variant. Another quote elsewhere in S3 does not contaminate the conclusion. In a paragraph containing both the neutral conclusion and a copied first-person statement, only the copied statement is reported. Ordinary analytical words—thành công, thất bại, lãnh đạo, ủng hộ, thời cơ, chính trị, quân sự, độc lập, suy yếu and chiến thắng—are not added to loaded-language rules. Grounding, unsupported entities/years, citations and comparison checks remain independent.

8. **Revalidation and stale state.** The audit found that `_check_answer` already invoked new citation and grounding checks after repair; it did not merge old viewpoint lists into the new answer. The repeated false positive came from rerunning the defective matcher. This pass makes the current validation snapshot explicit: stage, current viewpoint issues, target mismatches, uncited paragraphs, invalid aliases, unsupported names and unsupported years are replaced together on every check. Prior grounding diagnostics remain history only. Tests first produce real viewpoint/name/year/citation errors, then validate a clean repair with empty current lists. A separate comparison test clears a real wrong-target citation after repair.

9. **Narrow cause-evidence refinement.** Keep the same retriever, query planner, state machine, source quotas and comparison balancing. For cause questions, preview the existing bounded excerpt before coverage selection and annotate that visible text, rather than ranking a long source by dimensions that will be discarded. A small generic ranking preference favors causal connections, preparation, timing, organization, support, pressure and enabling conditions. Clearly poem/prediction, commemoration or aftermath sentences do not contribute causal dimensions; a source dominated by those sentences is downranked and does not count as strong causal evidence. Explicit requests for result/significance/consequence retain that material. The existing strong-evidence count and breadth thresholds are unchanged. The adaptive skip decision now checks the same selected excerpts. Tests retain three complementary cause chunks over higher-ranked poem/aftermath noise for both CMT8 and another event; a poem's economic/military vocabulary cannot inflate the selected excerpt's sufficiency. Character budgets, before/after compaction telemetry and source identifiers remain intact.

10. **Warm model calls and expected latency.** The supplied production request used two full generations, about 13.1 seconds synthesis plus 13.3 seconds repair. The new production-like fixture, with valid first-synthesis citations, uses **one model call**, `repair_used=false`, `full_quality_repair_used=false`, no viewpoint issues and `final_failure_reason=null`. It still plans two retrieval queries, executes one and skips the literal secondary query. History is empty, the model is ready, and compaction remains active. The expected saving is the unnecessary repair generation's cost, approximately 13.3 seconds in that supplied trace. No exact production speedup is asserted by the tests. Genuine substantive failures retain the existing bounded full repair; citation-only recovery, safe loading overlap and warm readiness behavior remain unchanged.
